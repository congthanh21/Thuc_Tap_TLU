# Thư mục dữ liệu

Tệp dữ liệu gốc không được đưa lên GitHub để tuân thủ giới hạn dung lượng và tối ưu kho lưu trữ.

1. Tải bộ dữ liệu **Online Retail II** từ [Kaggle](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci).
2. Đổi tên tệp tải về thành `online_retail_II.csv` và lưu trực tiếp vào thư mục này.

**Mô tả các biến (Cột):** `Invoice`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `Price`, `Customer ID`, `Country`.
